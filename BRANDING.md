# USSI Nexus brand guide

## Product lockup

The application product name is **USSI Nexus**. In compact navigation, render the supplied USSI Global circular mark with the two-line wordmark:

- `USSI`
- `Nexus`

Use **USSI Global** as the organization name in ownership, copyright, and legal contexts.

## Approved assets

| Asset | Use |
| --- | --- |
| `static/ussi_nexus_mark.png` | Favicon, sidebar, modal, and other compact product surfaces |
| `static/ussi_global_logo.png` | Sign-in and official USSI Global identity surfaces; display on white |

Do not recolor, redraw, stretch, rotate, or add effects inside the supplied corporate artwork. CSS may provide spacing, a circular crop for the mark, or a neutral container behind the on-white logo.

## Color system

| Role | Dark theme | Light theme |
| --- | --- | --- |
| Corporate navy | `#0B2B74` | `#0B2B74` |
| Corporate blue | `#0071BA` | `#0071BA` |
| Interactive accent | `#3AA7E8` | `#0071BA` |
| Accent hover/emphasis | `#78C9F2` | `#0B2B74` |

The lighter dark-theme accent is an accessibility adaptation for contrast on graphite surfaces. The supplied logo remains in its original corporate colors.

## Naming rules

- Page titles: `{Page name} · USSI Nexus`
- Main browser title: `USSI Nexus`
- Product footer: `© 2026 USSI Global · USSI Nexus`
- Generated Training document attribution: `Generated by USSI Nexus - Training Tracker`
- Runtime/server display name: `USSI Nexus Lucee`

Internal compatibility identifiers such as the existing database name, exception namespace, and `LOGICORE_AUTH` JavaScript handoff remain unchanged to avoid an unnecessary data migration or API break. They are not presented as product branding.
